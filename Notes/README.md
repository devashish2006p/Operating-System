# Operating System Notes – Structure Guide

This repository contains **Operating System notes organised by depth of understanding**,  
not by different topics.

---

## Basic Level
- Covers **ALL operating system topics**
- Focus on:
  - Clear definitions
  - Core concepts
  - Fundamental mechanisms
- Suitable for:
  - Beginners
  - First-time OS learners
  - Strong conceptual foundation

**No topic is skipped** at the Basic level.

---

## Intermediate Level
- Covers the **same topics as Basic**
- Goes deeper into:
  - Internal working
  - Algorithms
  - Data structures used inside OS
- Includes:
  - More examples
  - Better Linux mapping

 Topics are the same, **depth is increased**.

---

## Advanced Level
- Again covers the **same core OS topics**
- Focus on:
  - Kernel-level understanding
  - Real Linux implementation details
  - System calls, kernel structures
  - Performance, edge cases, internals
- Suitable for:
  - System programmers
  - Kernel learners
  - Security / hacking foundations

 Depth is **maximum**, topics are **not different**.

---

## Important Note

> **Basic, Intermediate, and Advanced do NOT mean different syllabus.**  
> They represent **different depths of the same Operating System topics**.

If a topic exists in `Basic`,  
it will also exist in `Intermediate` and `Advanced`,  
but explained with **increasing technical depth**.

---

## Topic Format

Each topic folder contains:

- `theory.md` → OS concepts & explanations
- `linux-tools & functions.md` → Linux tools, commands, system calls related to the topic

---

## Goal of This Structure

- Avoid fragmented learning
- Build OS knowledge layer by layer
- Map theory directly to Linux implementation
