# System Boot Process 

1. **Power ON**  
   When the system is powered on, electricity reaches the CPU, RAM, and motherboard.

2. **BIOS / UEFI Start**  
   BIOS or UEFI firmware starts running and takes control of the system.

3. **POST (Power-On Self Test)**  
   POST checks basic hardware like CPU, RAM, and keyboard to make sure they work properly.

4. **Boot Device Selection**  
   BIOS/UEFI selects the boot device such as HDD, SSD, or USB.

5. **Bootloader Load**  
   The bootloader (for example, GRUB) is loaded into memory from the boot device.

6. **Kernel Load**  
   The bootloader loads the operating system kernel into RAM.

7. **Kernel Initialization**  
   The kernel initializes CPU, memory management, device drivers, and hardware.

8. **Init / systemd Start**  
   The kernel starts the first user-space process called init or systemd.

9. **Services Start**  
   systemd/init starts system services and background processes.

10. **Login Screen**  
    The login screen or desktop appears and the system becomes ready to use.
