# 1. What is CPU and what actually CPU does?
CPU computer ka processor hai jo machine instructions execute karta hai. Tumhara C program directly CPU ko samajh nahi aata; compiler uske code ko machine instructions mein convert karta hai, jinhe compatible CPU execute kar sakta hai.
  - **Execution Cycle of CPU**
        1. Fetch : CPU ko pata hona cahiye ki next instruction kahan sa laani hai.
        2. Decode : Instruction ka machine code bits sa CPU determine karta hai ki kaunsa operation perform karna hai aur operands kahan hai.
        3. Execute : CPU operation perform karta hai.
       
  - **CPU har program q nahi chala shakta**
      - CPU machine instructions ka ek defined set ko support karta hai. Is set ko Instruction Set Architecture (ISA) kehte hai. Maan lo ek program x86-64 machine code mein compile hua hai. ARM CPU us machine code ko normally directly execute nahi kar sakta, kyunki instructions ka encoding aur unka meaning alag ho sakta hai. Isi liye compiler ko target architecture ke according machine code generate karna hota hai.
        
   
  - **Registers kya hai aur CPU ko inki zarurat kyun hai?**
    - CPU ko addition karni hai, lekin numbers RAM mein stored hain. Agar CPU har chhoti calculation ke liye baar-baar RAM se data laane ka wait kare, toh execution slow ho sakta hai. Isliye CPU ke andar bahut chhoti, bahut fast storage locations hoti hain, jinhe registers kehte hain.
      
        - **Special Registers** : CPU mein general-purpose registers ke alawa kuch special-purpose registers bhi hote hain. Inhe samajhna OS ke liye bahut important hai.
            1. Program Counter (PC) - Program Counter CPU ko batata hai ki instruction execution ke liye next instruction ka address kya hai. x86 architecture mein isse instruction pointer (RIP, 64-bit mode mein) kehte hain.
            2. Stack Pointer (SP) - Program functions ko call karta hai, local variables banata hai aur doosre functions ko arguments pass karta hai. In operations mein memory ka ek area, jise stack, commonly use hota hai. Stack Pointer stack ke relevant top ko track karne mein help karta hai.
            3. Program Status Word (PSW) - PSW ek status/control register ka general naam hai. Different CPU architectures mein iska naam aur exact structure alag hota hai. Ismein execution ki state se related information ho sakti hai, jaise:
                - Arithmetic operation ka result zero tha ya negative.
                - Comparison ke baad kaun-se condition flags set hue.
                - CPU kis privilege mode mein execute kar raha hai.
                - Interrupts ya doosre control mechanisms ki state.
              
    - **Difference Between Architecture and Microarchitecture**
      1. Computer Architecture: Computer architecture batati hai ki programmer ya software ke perspective se processor kya-kya operations perform kar sakta hai, jaise kaun-se instructions execute kar sakta hai, kaun-se registers available hain aur memory ko kaise access kar sakta hai.
      2. Computer Microarchitecture: Computer microarchitecture batati hai ki processor ke andar hardware components, jaise ALU, registers, control unit, pipelines aur caches, ko kis tarah organize aur implement kiya gaya hai taaki architecture mein defined instructions execute ho sakein.
