# 1. OS Generation 
OS Generation ka matlab hota hai Operating System ko generate ya configure karne ki process, jisme available hardware aur system requirements ke according OS ke required components aur features ko select karke ek particular system ke liye OS prepare kiya jata hai.

# 2. System Configuration
System Configuration ka matlab hai computer ke hardware aur OS ki settings ko apni requirement ke according set karna, taaki system properly kaam kare.
For example:
1. RAM aur storage ko properly manage/configure karna
2. Boot settings configure karna
3. Network settings configure karna
4. Users aur permissions set karna
5. Devices aur drivers configure karna
6. Services ko enable/disable karna

# 3. OS Tuning 
OS Tuning ka matlab hai Operating System ki settings ko performance, responsiveness, stability ya resource utilization improve karne ke liye optimize karna.
For example:
1. CPU scheduling ko optimize karna
2. Memory usage optimize karna
3. Unnecessary services disable karna
4. Disk I/O performance improve karna
5. Network performance optimize karna
6. System processes ko properly prioritize karna

# 4.  Kernel Compilation and Optimization
Kernel Compilation and Optimization ka matlab hai  kernel ke source code ko apni required configuration aur features ke according compile karke ek customized kernel banana aur usse performance/resource usage ke liye optimize karna.
