# 1. OS Optimization
Ya woh techniques aur mechanism hote hai jinka use operating system performance, efficiency, speed aur resource utilization improve karne ka lia karta hai. 
# 2. Optimization Techniques 
1. Buffering - Buffering ek optimization technique hai jisme data ko source aur destination ke beech transfer karne se pehle temporary memory area (buffer) me store kiya jata hai taaki speed mismatch handle kiya ja sake.
2. Caching - Caching ek optimization technique hai jisme frequently used data ko ek fast storage area (cache) me rakha jata hai taaki future accesses jaldi ho saken.
3. Spooling - Spooling (Simultaneous Peripheral Operations On-Line) ek optimization technique hai jisme multiple I/O requests ko temporary queue me store karke sequentially process kiya jata hai.
4. I/O Scheduling - I/O Scheduling ek optimization technique hai jisme OS multiple I/O requests ko kis order me execute karna hai ye decide karta hai taaki performance aur efficiency improve ho sake.
5. Asynchronous I/O - Asynchronous I/O ek I/O technique hai jisme process I/O request start karti hai aur uske complete hone ka wait nahi karti; I/O background me chalta rehta hai aur process apna dusra kaam continue kar sakti hai.
