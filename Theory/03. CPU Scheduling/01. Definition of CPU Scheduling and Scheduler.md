# CPU Scheduling and CPU Scheduler

## CPU Scheduling 

CPU scheduling is the process used by the operating system to decide **which process will use the CPU next** and **for how long**.

In a computer system, many processes exist at the same time, but the CPU can execute **only one process at a time**. Because of this limitation, the operating system must choose one process from the ready processes and assign the CPU to it. This decision-making process is called CPU scheduling.

CPU scheduling mainly works when:
- more than one process is in the ready state
- the currently running process is stopped, blocked, or finished
- the CPU becomes free

The goal of CPU scheduling is to:
- keep the CPU busy as much as possible
- give fair CPU time to all processes
- reduce waiting time of processes
- improve system responsiveness

CPU scheduling is the backbone of multitasking systems. Without CPU scheduling, multiple programs cannot run smoothly at the same time.

---

## CPU Scheduler 

CPU Scheduler is a part of the operating system that **implements CPU scheduling**.

It is responsible for:
- selecting one process from the ready queue
- deciding which process should get the CPU
- handing over the CPU to the selected process

The CPU scheduler runs whenever the CPU becomes idle or a scheduling decision is needed. It does not execute user programs itself; instead, it only **selects** the process that should run next.

The CPU scheduler works closely with:
- the ready queue
- scheduling policies
- dispatcher (which actually gives CPU control)

In simple words:
- CPU scheduling is **the decision**
- CPU scheduler is **the decision-maker**

The efficiency of an operating system heavily depends on how smart and fast the CPU scheduler is.

---

## Summary

CPU scheduling decides how CPU time is shared among processes.  
CPU scheduler is the OS component that performs this decision-making task.  
Together, they ensure efficient, fair, and smooth execution of processes.
