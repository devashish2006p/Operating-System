# 1. Process 
Process ek running program hota hai jise Operating System CPU par execute karwata hai aur uske liye memory, CPU time aur execution state jaise resources manage karta hai.

# 2. Structure of Process 
Structure of a process ka matlab hai process ke andar maujood user-space memory (code, data, heap, stack) aur kernel-space mein OS dwara maintain ki jaane wali process-management information (PCB, CPU context, scheduling information) ka organization.

  ## User Space Process Structure 
  User-space process structure mein process ke apne virtual address space ke andar Text/Code Segment, Data Segment, Heap aur Stack hote hain, jahan program ki instructions, variables, dynamically allocated memory aur function calls se related data store hota hai.
  ## Kernel Space Process Structure
  Kernel-space process structure mein OS process ko manage karne ke liye uska PCB (Process Control Block), process state, PID, scheduling information, saved CPU registers/context, memory-management information aur open files se related information maintain karta hai.

# 3. Process Management 
Process management is a core function of an operating system that deals with the creation, execution, scheduling, coordination, and termination of processes while efficiently sharing CPU and system resources.

# 4. Executable File Format
Executable File Format ek predefined structure hota hai jisme executable file ke andar program ki machine instructions, data, memory-layout ki information aur zaroori metadata organize hote hain, taaki Operating System use memory mein load karke execute kar sake; Ex - ELF (Linux), PE (Windows), Mach-O (macOS) etc. 
- **Functions**
  1. Code Organization: Program ki machine instructions aur data ko executable file ke andar structured form mein organize karta hai.
  2. Memory Mapping: Operating System ko batata hai ki program ke different sections ko memory mein kaise load aur map karna hai.
  3. Entry Point Identification: Program execution kahan se start karna hai, uski information provide karta hai.
  4. Linking Support: External libraries aur symbols ko link karne ke liye required information store karta hai.
  5. Dynamic Linking: Runtime par shared libraries ko load aur resolve karne ke liye necessary information provide karta hai.
