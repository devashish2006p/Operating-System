## Process Creation and Termination

### Process Creation
Process creation means creating a new process in the **New** state under the OS, so it can be ready for CPU execution.

**Mechanism of Process Creation:**
1. **Parent Process Decide** – An existing process decides to create a new process.  
2. **OS Resource Allocation** – OS assigns a unique Process ID (PID), allocates memory, copies or creates open files list, creates PCB, and other necessary resources.  
3. **Process Context Initialization** – Program counter is set to next instruction, CPU registers are reset, scheduling info initialized. Process moves from **New → Ready** queue.  
4. **Parent-Child Relationship Set** – Parent PID is stored in PCB, child process linked to parent.  
5. **Ready State Placement** – Scheduler queues the process for CPU availability and transition from **Ready → Running**.

---

### Process Termination
Process termination means the execution of a process is complete or forcefully ended, and the OS frees all allocated resources.

**Mechanism of Process Termination:**
1. **Process Completes Execution** – All instructions are executed, task finished.  
2. **OS Resource Deallocation** – Memory, files, and other allocated resources are freed.  
3. **Parent Notification** – Parent receives the exit status.  
4. **Process Removed from Scheduling** – Process state changed to **Terminated**, scheduler ignores it.

---

### Types of Termination
1. **Normal Termination** – Process finishes execution on its own.  
2. **Abnormal / Forced Termination** – OS or user kills the process.  
3. **Parent Termination** – If parent process terminates, child becomes an **orphan process**; OS assigns a new parent.
