# 1. Paging
Paging ek memory-management technique hai jisme process ke virtual address space ko fixed-size units, yani pages, aur physical memory ko same-size fixed units, yani page frames, mein divide karke virtual pages ko physical frames mein map kiya jata hai.

# 2. Main Components of Paging
1. Page - Page virtual address space ka fixed-size block/unit hota hai, jisme process ki virtual memory ko equal-size parts mein divide kiya jata hai; jaise 64 KB virtual memory aur 16 KB page size ho to 4 pages banenge.    Pasted markdown
2. Page Frame - Page Frame physical RAM ka fixed-size block/unit hota hai, jiska size exactly Page ke size ke barabar hota hai, aur ismein ek virtual page ko store kiya ja sakta hai.
3. Page Table - Page Table ek per-process data structure hai jo ye mapping maintain karti hai ki process ka kaunsa Virtual Page (VP) physical memory ke kis Page Frame (PF) mein located hai, jisse virtual address ko physical address mein translate kiya ja sake.

# 3. Memory Organization
## 1. Physical Memory Organization
  1. Physical RAM ko fixed-size, equal-sized blocks mein logically divide kiya jata hai, aur har block ko Page Frame kaha jata hai.    
  2. Har Page Frame ka size exactly ek Virtual Page ke size ke barabar hota hai, isliye ek frame ke andar ek page rakha ja sakta hai.    
  3. Physical memory ke frames contiguous sequence mein numbered hote hain, jaise Frame 0, Frame 1, Frame 2, Frame 3, etc.    
  4. Kisi process ke virtual pages ko physical memory ke alag-alag available frames mein rakha ja sakta hai, yani pages ka physical placement contiguous hona zaroori nahi hai.    
  5. Kuch page frames OS khud ke liye reserve/use kar sakta hai, isliye physical RAM ke saare frames processes ko nahi diye jaate.    
  6. Kuch frames free bhi reh sakte hain, aur OS un free frames ko track karke future page allocation ke liye use karta hai.    
  > Core idea: Paging mein physical memory ko fixed-size Page Frames mein organize kiya jata hai, aur virtual pages ko in frames mein non-contiguously place kiya ja sakta hai.

## 2. Logical Memory Organization 
  1. Process ka virtual address space fixed-size equal units mein divide hota hai, aur in units ko Pages kaha jata hai.    
  2. Har Page ka size same hota hai, example mein 64-byte address space ko 16-byte ke 4 pages mein divide kiya gaya hai.    
  3. Pages ko Virtual Page Number (VPN) se identify kiya jata hai, jaise Page 0, Page 1, Page 2 aur Page 3.    
  4. Har virtual address logically do parts mein divided hota hai: VPN aur Offset, jahan VPN batata hai address kis page mein hai aur Offset us page ke andar required byte/location batata hai.    
  5. Virtual pages ka physical memory mein contiguous hona zaroori nahi hai, kyunki har page independently kisi bhi available page frame mein map ho sakta hai.    
  6. Page Table har virtual page ki physical frame ke saath mapping maintain karti hai, jisse virtual memory ki logical organization ko physical memory se connect kiya ja sake.    
  > Core idea: Paging mein process ki logical/virtual memory ko same-size Pages mein divide kiya jata hai, aur har virtual address VPN + Offset ke form mein represent hota hai.

# 4. Memory Tracking Methods
1. Free Frame List — OS physical memory ke currently free page frames ki list maintain karta hai, aur jab kisi process ko page frame chahiye hota hai to list mein se ek ya required number of free frames select karke allocate kar deta hai.
2. Bitmap / Bit Vector — OS har page frame ke liye ek bit maintain karta hai, jahan bit ki value batati hai ki frame free hai ya allocated, aur allocation/deallocation ke waqt corresponding bit ko update kar diya jata hai.

# 5. Memory Allocation in Paging
  1. Program execute hota hai, to OS process create karke uske liye virtual address space establish karta hai.
  2. Process ki virtual memory ko fixed-size pages mein divide kiya jata hai.
  3. Physical RAM ko bhi same fixed size ke page frames mein divide kiya jata hai.
  4. Process ko memory chahiye hoti hai, to OS required virtual memory region create/map karta hai; is stage par har page ko turant physical frame milna zaroori nahi hota.
  5. Jab process kisi virtual page ko actually access karta hai, to CPU us virtual address ko use karta hai.
  6. CPU virtual address ko VPN (Virtual Page Number) aur Offset mein divide karta hai.
  7. MMU page table ke through VPN ka corresponding physical frame dhoondhta hai.
  8. Agar page pehle se physical frame mein mapped hai, to translation complete hoti hai aur CPU us physical location ko access karta hai.
  9. Agar page present nahi hai, to Page Fault generate hota hai aur control kernel ko chala jata hai.
