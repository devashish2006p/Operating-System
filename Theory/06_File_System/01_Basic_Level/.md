# 1. Introduction To File System
File System Operating System ka ek essential part hota hai jo storage devices par data ko files aur directories ka form ma organize aur manage karta hai.
Jab hum computer ma koi data save karte hai to wo directly raw disk me random form ma store nahi hota. File system us data ko structured format ma convert karke store karta hai taki OS aur user dono easily access kar sake. 

## 1.1 Role of File System 
  - Data ko files ma store karna
  - Files ko folders (directories) ma organize karna
  - Data ko read/write/modify karna
  - Storage space ko manage karna
  - Files ko secure aur accessible banana
    
## 1.2 Data vs File vs Storage 
| DATA | FILE | STORAGE |
|------|------|---------|
| Data raw form me hota hai, jiska koi proper structure nahi hota. | File ek organized data hota hai jiska ek name hota hai aur OS usko manage karta hai. | Storage ek physical device hota hai jahan data aur files permanently save hote hain. |
| Example: 101, "Dev", 75% | Example: marks.txt jisme student ke marks structured form me stored hote hain. | Example: HDD, SSD, Pen drive |
| Data sirf information hota hai jo processing ke baad meaningful ban sakta hai. | File data ko ek identity aur format deta hai jisse OS easily handle kar sake. | Storage actual memory space provide karta hai jahan files exist karti hain. |

# 2. File Basics
File ek aisa named data unit hota hai jisme related information ko organized form ma store kiya jata hai aur OS us file ko storage device par ushke name aur metadata ka through manage karta hai taki us data ko easily store, access aur modify kiya ja sake. 

## 2.1 Types of File
**There are two types of files**
1. **Text Files** - Ya wo file hoti hai jisme data human-readable form ma store hota hai. Ishme data characters (letters, numbers, symbols) ka form ma store hota hai jise directly human read kar shakta hai.
   
2. **Binary Fles** - Ya wo file hoti hai jisme data machine-readable form (0s and 1s) me store hota hai, ishme data raw binary form ma store hota hai jo directly human readable nahi hota sirf machine interpret karti hai. 

## 2.2 File Attributes 
**File Attributes** wo properties/metadata hote hai jo ksi file ka bare ma information dete hai, bina file ka actual data dekhe. 

1. **Name** - Ya file ka official identifier/name hota hai jissa user aur OS file ko identify karte hai. Ex - notes.txt (Yahan notes file name hai aur .txt extension/type indicator hai). 
2. **Size** - Ya btata hai ki file kitni storage use kar rhi hai. Ex - 2KB, 10MB, 1GB. 
3. **Type** - Ya btata hai ki file kis nature/format ki hai. Ex - Text file, Binary file, Image etc. 
4. **Location (Path)** - Ya btata hai ki file storage device ma logically kahan present hai. Ex - /home/user/notes.txt
5. **Permssions** - Ya define karta hai kaun file ka sath kya operation kar shakta hai. 
6. **Time Stamps** - Ya file sa related timing information store karta hai. 
7. **Owner/User info** - Ya btata hai file kis user ya process ki hai.
   
# 3. File Operations 
File operations wo actions hote hai jo OS ksi file par perform karta hai taki users file ko use aur manage kar sake. 
1. Create Operation - Ishka use nayi file banane ka liye kiya jata hai jisme OS file ka naam, metadata aur initial storage structure create karta hai.
2. Open Operation - Open operation ka use kisi existing file ko access karne ke liye kiya jata hai taaki uspar read ya write operations perform kiye ja sake.
3. Read Operation - Read operation file ke andar stored data ko storage device se retrieve karke user ya program ko provide karta hai.
4. Write Operation - Write operation file me naya data add karne ya existing data ko modify karke storage device par save karne ka kaam karta hai.
5. Close Operation - Close operation file ke current access session ko terminate karta hai aur OS used resources ko release kar deta hai.
6. Delete Operation - Delete operation file ko file system se remove karta hai aur uske occupied storage space ko free mark kar deta hai.
7. Rename Operation - Rename operation existing file ka naam change karta hai bina uske actual data ko modify kiye.
   
# 4. File Access Methods 
File access method wo technique hota hai jo define karta hai ki file ka ander stored data ko kis tarah access kiya jayega. 

## 4.1 Types of Access Methods
1. Sequential Access - Ya ek aisa file access method hai jisme file ka data ko ushke stored order ka according ek ka baad ek access kiya jata hai aur ksi specfic record tak pahuchne ka lia usshe pehle wale records ko pass karna parta hai.

2. Direct Access - Ya ek aisa file access method hai jisme file ka ksi bhi record ya location ko directly access kiya ja shakta hai bina usshe pehle wale records ko sequentially read kiye. 

3. Indexed Access - Ya ek aisa file access method hai jisme file ka records tak pahunchne ka lia ek alag index structure maintain kiya jata hai jo record ki location ki information rakhta hai aur us index ki madad sa required record ko quickly access kiya jata hai.
   
# 5. Directory System 
Ya ek organizational structure hai jo storage device par maujood files ko systematc tareeke sa arrange karta hai taki unhe easily dhoonda aur manage kiya ja sake. 

## 5.1 Purpose of Directory System
1. Organization - Files ko logical groups ma arrange karna.
2. Searching - File ko jaldi locate karna.
3. Naming - Same files names ko allow karna.
4. Management - Files ko move, copy, delete aur group karna easy ho jata hai.  

## 5.2 Types of Directory 
1. Single -level directory - Ya ek simplest directory structure hota hai jisme sari files ek hi directory (folder) ka ander store hota hai aur koi sub-directory nhi hota.
   
2. Two level directory - Ishme har user ki apni seperate directory hoti hai aur sab users ki directories ek main root directory ka ander hoti hai. 

3. Tree structured directory - Ya ek hierarchical file system structure hota hai jisme directories ka ander sub-directories ho shakti hai, aur har directory ka ander files and aur bhi directories organized form ma store hoti hai. 

4. Acyclic Graph directory - Ya ek advanced directory structure hota hai jisme files aur directories multiple parents ka under share ho shakta hai, lekin koi circular loop allowed nhi hota. ya aisa directory system hai jisme ek file ya folder ek sa zyada jagha link ho shakta ha. 
   
# 6. File Path System 
Path ek address hota hai jo btata hai ki file ya directory file system ka ander kis location par maujood hai. 

## 6.1 Types of File Paths
1. Absolute Path - Ya wo path hota hai jo root directory sa start hota hai aur file ya directory tak pahunchne ka poora exact route btata hai. Ex - /home/gautam/Documents/notes.txt

2. Relative Path - Ya ek aisa path hota hai jo current working directory ko starting point maan kar file ya directory tak pahunchne ka route batata hai, aur ishme root drectory se poora address specify nhi kiya jata. Ex - Documents/notes.txt

## 6.2 Path Notation Symbols
Ya ek special symbols hote hai jo file path likhne ko short, convenient aur flexible banata hai. 
Ex :- 
/home/gautam/Documents (Mann lo ya current directory hai). To agr user directory ko hi represent karna cahe to wo poora path likhne ki jagha *.* likh shakta hai. 

**Types of Path Notation**
1. Current Directory (.) - Ya ek path notation symbol hai jo us directory ko represent karta hai jisme process ya user is samay kaam kar rha hota hai. Ishka use tab kiya jata hai jab hume explicitly current direcotry ko refer karna ho bina ushka poora path likhe. 

2. Parent Directory (..) - Ya current directory ka turant uper wali directory ko represent karta hai. 

3. Home Directory (~) - Ya user ki personal home directory ko represent karta hai. 

4. Root Directory (/) - Ya sbse top level directory hoti hai, jiske ander poore file system ki baaki sab directories aur files directly ya indirectly maujood hoti hai. 

# 7. Storage Foundation 

## 7.1 Introduction to Storage 
Storage computer ka wo mechanism ya medium hota hai jo data, programs aur information ko save karke rakhta hai taki unhe zarurat parne par baad ma retrieve aur use kiya ja sake. 
- **Need** - Ishke jrurat isiliye hoti hai qoki computer ke data aur programs ko permanently ya temporarily preserve karke rakhna hota hai taki power off hone ka baad bhi information available rahe aur future ma dobara access kiya ja sake.
- **Purpose** - Ishka main purpose data ko securely store karna, organize karna aur zarurat parne par efficiently retrieve karna hota hai. Ishme user data (documents, photos, videos), programs, operating system files, application files aur system related information store ki jati hai. 

## 7.2 Storage Device Categories 
1. **Magnetic Storage Devices** - Ya ek non-voletile storage device hota hai jo data ko magnetic material ki surface par magnetic patterns (0 and 1) ke roop ma store karta hai, jiska purpose large capacity, long term, permanent aur cost-effective data storage provide karna hota hai taki OS, applications aur user data ko power off hone ka baad bhi safely preserve karke rakha ja sake. (HDD basically sequential aur random dono types of access methods use karti hai). 

- **1.1 Need** - Magnetic Storage Devices ko isliye banaya gaya tha kyunki computers ko aise storage ki zarurat thi jo bahut zyada data ko permanently store kar sake, power off hone par bhi data na mitaye, aur us samay ki memory technologies ke mukable kam cost me large-capacity storage provide kare; isne limited storage capacity, high storage cost aur non-permanent data storage ki problem ko solve kiya.
- **1.2 Internal Components (HDD)**
  1. Platter - Ya HDD ka ander maujood ek circular disk hota hai jiski surface par magnetic material ki coating lagi hoti hai aur isi surface par actual data store kiya jata hai. Ishka main kaam data ko magnetic form ma store karne ka lia physical storage surface provide karna hota hai. 
  2. Spindle - Ya HDD ka center ma maujood ek rotating shaft hoti hai jo platters ko pakarkar high speed par ghumati hai. Ishka main role platters ko constant high speed par rotate karna hota hai taki Read/Write head platter ka different parts tak pahunch sake aur data ko read ya write kar sake. 
  3. Read/Write Head - Ya HDD ka ek electromagnetic component hota hai jo platter ki magnetic surface par data ko write karta hai aur wahan sa data ko read karta hai. Ishka kaam platter aur computer ka beech data transfer karna hota hai.
  4. Actuator Arm - Ya HDD ka ander maujood ek machenical arm hoti hai jo Read/Write head ko platter ki surface par alag-alag locations tak le jane ka kaam karta hai. Ishka kaam read/write head ko platter ke correct track aur location tak move karna hota hai taki data read ya write kiya ja sake. 
  5. Actuator - Ya HDD ka ander maujood ek electromechnical mechanism hota hai jo Actuator Arm ko control aur move karta hai taki Read/Write head ko platter ki sahi location tak pahunchaya ja sake. Ishka kaam Actuator Arm ko bahut precise tareeke sa control karna aur Read/Write head ko platter ka required track tak pahunchana hota hai. 
  6. Controller Board - Controller Board HDD ka electronic control unit hota hai jo HDD ke sabhi components ko control karta hai aur computer aur HDD ke beech communication manage karta hai. Ishka main role HDD ke operations ko coordinate karna, data transfer manage karna aur HDD ke components ko control karna hota hai.
  7. Magnetic Surface - Magnetic Surface platter ki wo specially coated surface hoti hai jahan actual data magnetic patterns ke roop me store kiya jata hai. Ishka main role binary data (0 aur 1) ko magnetic states ke roop me permanently store karna hota hai.
- **1.3 Internal Mechanism**
  1. Jab HDD ko power milti hai to spindle motor platters ko high speed par rotate karna suru kar deti hai.
  2. Platters ke rotate hone ka bad unki magnetic surface Read/Write Head ka neeche continuously pass hone lagti hai.
  3. Jab Operation System ksi file ko read ya write karne ki request bhejta hai to ye request HDD ka controller board tak pahunchti hai.
  4. Controller board request ko process karke determine karta hai ki required data platter ke kis location par maujood hai ya kis location par store kiya jana hai.
  5. Controller Board actuator ko command deta hai taki actuator arm read/write head ko platter ke correct track aur position tak move kar sake.
  6. Actuator Arm read/write head ko required location ka uper bahut precise tareeke sa position kar deti hai.
  7. Agr write operation ho rha ho to read/write head magnetic surface ke particles ki magnetic orientation ko change karke data ko 0 aur 1 ka roop ma store karti hai.
  8. Agr read operation ho rha ho, to read/write head magnetic surface par pehle sa stored magnetic patterns ko detect karti hai aur unhe binary data ma convert karti hai.
  9. Read kiya gya data controller board ko bheja jata hai jo us data ko computer aur OS tak transfer kar deta hai.
  10. Write operation ka dauran controller board computer sa aaya hua binary data Read/Write head ko bhejta hai, jo us data ko magnetic surface par store kar deti hai.
  11. Poore operation ka dauran controller board spindle speed, actuator movement aur data transfer ko continuously monitor aur control karta rehta hai.
  12. Operation complete hone ka baad HDD agle read ya write request ka wait karti hai aur platters rotate karte rehte hai.
- **1.3 HDD Read Process**
1. Jab user koi file save karta hai, to operating system us file ke data ko binary form (0 aur 1) me HDD ko bhejta hai.
2. Data sabse pehle HDD ke Controller Board tak pahunchta hai.
3. Controller Board decide karta hai ki platter ke kis location par data store kiya jayega.
4. Controller Board Actuator ko command deta hai aur Actuator Arm Read/Write Head ko us target location tak le jati hai.
5. Spindle platters ko continuously rotate karta rehta hai taaki required location Head ke neeche aa sake.
6. Read/Write Head magnetic field generate karti hai aur magnetic surface ke particles ki magnetic direction ko change karti hai.
7. Particles ki magnetic orientation change karke binary values (0 aur 1) represent ki jati hain.
8. Is tarah binary data magnetic patterns ke roop me platter ki magnetic surface par permanently store ho jata hai.

- **1.4 Hdd Data Read Process**
1. Jab user kisi file ko open karta hai, to operating system HDD se us file ka data request karta hai.

2. Request HDD ke Controller Board tak pahunchti hai.

3. Controller Board file ki storage location identify karta hai.

4. Controller Board Actuator ko command deta hai aur Actuator Arm Read/Write Head ko required location tak move karti hai.

5. Spindle ke rotation ki wajah se required magnetic patterns Head ke neeche aate hain.

6. Read/Write Head magnetic surface par stored magnetic patterns ko detect karti hai.

7. Detected magnetic patterns ko binary data (0 aur 1) me convert kiya jata hai.

8. Ye binary data Controller Board ko bheja jata hai.

9. Controller Board data ko operating system aur application tak transfer kar deta hai.

10. Operating system us binary data ko process karke user ko file, image, video ya program ke roop me dikha deta hai.

- **1.5 Data Representation**
1. HDD kisi bhi data ko directly text, image, video ya program ke roop me store nahi karta, balki use pehle binary data (0 aur 1) me convert kiya jata hai.

2. Operating System aur computer ke components user ke data ko binary form me convert karke HDD ko bhejte hain.

3. HDD ke platter ki surface par ek magnetic coating hoti hai jisme bahut chhote magnetic particles maujood hote hain.

4. Read/Write Head in magnetic particles ki magnetic orientation ko change karke binary data ko represent karti hai.

5. Har magnetic orientation ek binary value (0 ya 1) ko represent karti hai.

6. Binary data ki poori sequence magnetic patterns ke roop me platter ki magnetic surface par store ki jati hai.

7. Jab data ko read karna hota hai, to Read/Write Head magnetic patterns ko detect karti hai.

8. Detected magnetic patterns ko wapas binary values (0 aur 1) me convert kiya jata hai.

9. Binary data ko operating system process karke user ke liye text, image, video ya program ke roop me present karta hai.

10. Is prakriya ke karan HDD ke andar actual me sirf magnetic patterns store hote hain, jabki user ko meaningful information dikhai deti hai.

- **1.6 Advantage**
1. HDD bahut adhik storage capacity provide karti hai, jisse large amount ka data store kiya ja sakta hai.

2. HDD ki cost per gigabyte ya terabyte SSD ke mukable kaafi kam hoti hai, isliye large storage ke liye ye economical option hai.

3. HDD non-volatile storage device hoti hai, isliye power off hone ke baad bhi data safe rehta hai.

4. HDD operating systems, applications, documents, videos aur backups ko long-term store karne ke liye suitable hoti hai.

5. Large-capacity HDDs market me aasani se uplabdh hoti hain aur unka storage size kai terabytes tak ho sakta hai.

- **1.7 Disadvantage**
1. HDD me moving mechanical parts hote hain, isliye isme mechanical failure ka risk rehta hai.

2. HDD ki read aur write speed SSD ke mukable kaafi kam hoti hai.

3. Spinning platters aur moving actuator ki wajah se HDD me access time zyada lagta hai.

4. Mechanical components ke karan HDD physical shocks aur vibrations ke prati zyada sensitive hoti hai.

5. HDD operation ke dauran SSD ki tulna me adhik noise aur heat generate kar sakti hai.

2. **Solid-State Storage Devices**
SSD (Solid State Drive) ek storage device hai jo NAND flash memory ka use karke data ko electronically store karta hai bina kisi moving parts ke, aur iska role fast, reliable aur low-latency data storage provide karna hota hai jo traditional HDD se kaafi zyada speed aur efficiency deta hai.

- **2.1 Need** - NAND Flash ki need isliye padi kyunki traditional storage (HDD) slow, mechanical aur power-hungry tha, jabki NAND flash ek non-volatile, fast, shock-resistant aur low power semiconductor memory provide karta hai jisse high-speed storage, instant access, portable devices (USB, SSD, smartphones) aur better performance possible ho gayi.
- **2.2 Internal Structure**
**There are three Core layers in SSD**
  1. Host/Interface Layer - Ya CPU/OS aur SSD ka beech communication layer hoti hai jo commands (read/write) aur data transfer ko manage karti hai. 
    - **Internal Components**
      1. Host Interface Controller - CPU/OS sa commands receive karta hai (Sata Controller/NVMe controller side).
      2. Command Queue System - Read/Write requests ko line ma manage karta hai.
      3. Data Buffer (Cache) - Temporary data hold karta hai fast transfer ka lia.
      4. Protocol Engine - SATA/NVMe rules ka according data packets encode/decode karta hai.
      5. Register Interface - Status, command aur data registers jissa CPU interact karta hai.
    - **Internal Mechanism**
      1. CPU/OS driver SSD ko WRITE command command register me bhejta hai.
      2. SSD controller command decode karke status register me BUSY set karta hai.
      3. OS/DMA system memory se data ko SSD controller ke data buffer me transfer karta hai.
      4. Controller data par ECC check + logical-to-physical mapping apply karta hai.
      5. Data ko page buffer me load karke NAND flash cells me program (write) karta hai.
      6. Write complete hone par controller status register me READY set karta hai.
      7. SSD controller CPU ko interrupt bhejta hai (completion signal).
      - **Read**
      8. CPU/OS driver SSD ko READ command command register me bhejta hai.
      9. Controller NAND flash se required data ko page buffer me load karta hai.
      10. Data par ECC correction + validation hota hai.
      11. Data controller buffer me move hota hai.
      12. DMA system data ko SSD buffer se system memory me transfer karta hai.
      13. Controller status register me READY set karta hai.
      14. SSD controller CPU ko interrupt bhejta hai (data ready signal).
      15. CPU memory se data read karke process complete karta hai.

   2. Controller Layer - Ya SSD ka brain hota ai jo data ko NAND flash main kaisa store karna hai decide karta hai. Mapping, ECC, wear leveling, garbage collection sab yahi handle karta hai.  
  3. Memory layer - Ya actual physical storage layer hoti hai jahan data electrons ka form ma memory cells ka ander permanently store hota hai.
